# Customer Support Ticket Dashboard

A SaaS-style Customer Support Ticket Dashboard built using HTML and CSS.  
This project simulates a real-world support system interface where teams can manage customer issues, track ticket status, and monitor support performance.

---

## 📊 Project Overview

Customer support dashboards help organizations manage incoming issues efficiently.  
This dashboard provides a clean and structured interface to:

- View support tickets
- Track ticket priority
- Monitor ticket status
- Manage customer information
- Review support performance metrics

The design follows modern SaaS UI patterns used in tools like Zendesk, Freshdesk, and Jira.

---

## 🖥 Pages Included

### 1. Dashboard
Overview of customer support tickets with status indicators.

### 2. Tickets
Detailed list of all support tickets including:
- Ticket ID
- Customer name
- Issue type
- Priority level
- Ticket status

### 3. Customers
Displays customer information derived from ticket records.

### 4. Reports
Shows support metrics such as:
- Total tickets
- Open tickets
- Closed tickets
- Pending tickets
- Customer satisfaction

### 5. Settings
Basic account configuration interface.
