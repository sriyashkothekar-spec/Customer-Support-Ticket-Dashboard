# E-Commerce Customer Segmentation

This project analyzes customer purchasing behavior using clustering techniques to identify meaningful customer segments. The goal is to help businesses understand different types of customers and create targeted marketing strategies.

---

## 📊 Project Overview

Customer segmentation is a key strategy in e-commerce that allows companies to:

- Identify high-value customers
- Understand purchasing patterns
- Detect at-risk customers
- Improve marketing effectiveness
- Personalize customer experience

This project uses data visualization and clustering techniques to group customers based on their behavior.

---

## 📈 Visualizations Included

The project includes the following analysis graphs:

- Cluster visualization of customers
- Optimal cluster count (Elbow method)
- Dendrogram for hierarchical clustering
- Purchase distribution analysis
- Unit price distribution
- Top selling products
- Country-wise sales analysis
- Purchases per customer distribution
